# Pixel-_ (new Roblox game, started 2026-11-07)

Working title "Pixel Depth". Status: **prototype v3** (2026-11-08): a shared voxel camp hub (bird's-eye camera) and private 3D cave mines played in first person; the first minute plays end to end. Current state and gaps: `Roblox Dev/Projects/Pixel-_/Prototype 1 Status.md`. Spec: `Roblox Dev/Projects/Pixel-_/Briefs/Game Spec v1 for Gemini.md`.

- **Direction (the user, 2026-11-08):** the hub is third person, bird's-eye, slightly behind the player; the mine is first person. The look follows the user's Miro board "3D Design" (Pixel Depths v1.5: voxel art, chunky chibi, hue-shifted pastel night palette, Hollow Mountain inside the World Tree roots). The side-scroller is dropped.
- Place: `Pixel Depth.rbxlx`. Scripts mirrored in `src/`: `Config.luau` = ReplicatedStorage.Shared.Config, `PixelText.luau` = ReplicatedStorage.Shared.PixelText (Pixelify Sans bitmap font), `HubBuilder.luau` = ServerScriptService.HubBuilder (the voxel hub, built by the server at start), `PixelServer.server.luau` = ServerScriptService.PixelServer (mines, digging, economy, lift), `PixelClient.client.luau` = StarterPlayerScripts.PixelClient (cameras, HUD, FX, sound). Push with `..\..\tools\studio_push.py`; test the first minute in Play with `python "Games/Pixel Depth/spike/play_test.py"` (keyboard driven: E dig, Q lift, G forge). An empty place is rebuilt from the repo with `sh spike/rebuild_place.sh`. Studio test hooks: player attributes DevGold, DevEggs, DevRow, DevCave.
- Hub v4 (2026-11-08): 4x the v3 area (stores on a ring at radius about 40, plaza ellipse 46 x 52, Hollow Mountain wall at about 95, World Tree trunk at z = -128, rear cliff with a stairway). Stores wear 32 px pixel textures from `art/pd_hub_tex.py` (ids `art/roblox_tex/hub/asset_ids.json`, applied with `skin()`/`tvox()` in HubBuilder). References, texture table and grades: `art/hub/refs/README.md`; capture views with the Edit-mode camera script pattern in that note's grades.
- Town v5 (2026-11-08): terraces, stream, bridges, winding lanes, trees v2, mining clutter (HubBuilder); grades in `art/hub/refs/README.md`. Hatch reveal v2 in `PixelClient.hatchShow` follows motionbykrit's card reveal (vault `Research/VFX and Animation/Reveal Juice - motionbykrit (2026-11-08).md`). Record motion with `..\..\tools\record_window.py` using the Hunyuan3D venv python (system Python has no OpenCV); trigger a hatch in Play by firing ReplicatedStorage Fx "hatch" <pet> from the Server.
- UI: the soft pastel kit v3 `art/ui_soft` (generator `art/pd_ui_soft.py`, 9-slice centres in `slices.json`, ids in `asset_ids.json`, refs `refs.md`; Fredoka One; the user 2026-11-08: the pixel kit did not fit). Older kits `art/ui_pixel`, `art/ui_pastel` are retired; icons `art/ui` stay for now. Caves Play test: `python "Games/Pixel Depth/spike/cave_mg_play.py" <prefix>` (deposits, both minigames, banking).
- Pickaxes: `blender/` (builder `pickaxe_hero.py`, `specs/`, `build_all.sh`, outputs in `blender/out/`); 3D viewer https://claude.ai/artifact/PztRmp6gewqeNx9GV3apsK.
- **All UI and art come from the design boards (the user, 2026-11-08):** Claude Design board https://claude.ai/artifact/PuHdRUnt1QTJcf5sxtyQT1 (UI kits, HUD, Forge) and the Miro "3D Design" board for the world direction. Change the board first, then build Roblox from it.
- **Z-fighting check (the user, 2026-11-08):** after any world or prop change, run `spike/zfight_scan.luau` in Play (Server: `python tools/studio_live.py execute_luau --file "Games/Pixel Depth/spike/zfight_scan.luau" code '{"datamodel_type":"Server"}'`) and fix new coplanar overlaps before calling it done (2026-11-08 baseline: hub 789 pairs, caves 62).
- **Script size (2026-11-09):** Roblox refuses a Source over 200,000 characters. PixelClient sits near 161,000 after moving the forge (`src/ForgeUI.luau`) and the Gloom client (`src/GloomClient.luau`) into ReplicatedStorage.Shared modules; build new client features the same way (a module with `start(E)`, E = the helpers it needs) and check the size before pushing.
- **Glass and gameplay night pass (2026-11-10):** new Shared modules `Radial` (round progress), `SurvivalHUD` (the talisman: torch ring, fear face, hearts, flare), `CartFX` (lantern fixtures, rider hands, chassis spring, motes, speed lines), `VeinRushUI` (the 3D crystal spire), `OreIcon` (live voxel ore for cards), `ViewHands` (first-person hands and swing springs), `WardrobeUI` (cosmetics data, `apply`, the wardrobe screen; server remote `Wear`). `UpgradeTracker` owns the left HUD column (a `UIListLayout`; other modules add a square button with `E.addRow`) and keeps the top-centre cards clear of both columns. Full-screen panels register with `E.addModal` (scrim, blur, prompts off, HUD hidden).
- **Quests, tutorial and juice (2026-11-10):** `Quests` (Shared: story chain = the tutorial, daily pool, rules; the server counts with `quest(s, event, n)` and pays through the `Quest` remote), `QuestUI` (the QUESTS panel on J, the step-card hint via `forgeUI.questHint`, the screen-space guide marker), `Juice` (emotes on shop, purchase, hatch, chest and claim; walking dust; beating egg hearts). First-person swing variants, torch sway, flare thrust and landing dip are in `ViewHands`. Brief: vault `Briefs/Quest Menu and Tutorial (2026-11-10).md`. BillboardGuis made by Shared modules did not draw: use screen-space markers.
- **Sound (2026-11-10):** 18 soft CC0 sounds from Kenney's packs replace the Creator Store set; files, sources and ids in `audio/sfx/README.md`, table `SFX` in PixelClient (`sfx(name, pitch)`, passed to modules as `E.sfx`). Panels, toasts, footsteps, landing, quest claim and hatch have their own sounds. Not heard by Claude.
- **Lighting style:** the game is tuned for `Lighting.LightingStyle = Realistic` (wet rock and glass reflect; the town is a real night). Scripts cannot set it: it is set in Edit mode (`spike/rebuild_place.sh` does it) and must be saved with the place.
- **Night helper:** `python spike/night.py push|play|stop|lua|shot|key|sizes` (push stops Play first and creates missing modules); `spike/grade_night.py <round>` captures one picture per audit item; `spike/hud_overlap.luau` (Client) reports HUD rectangle overlaps; `spike/mg_night.py` plays both minigames.
- World technique: mines are cells kept as data; only rock faces that look into the open cave near the player are Parts (flood fill). Not Terrain, not EditableMesh.

## Lessons carried over from the archived xianxia game (`..\Xianxia`)
- Pick an art style we can build reliably: avoid hand-modelled organic hero assets (hair, fur, dragons) as the core of the look.
- For any model from concept art: trace every part on each view at zoom with a grid and overlay the trace before building; keep each part under its triangle budget so nothing gets decimated.
- Keep the setup lean: one folder, one repo, few standing rules. Add rules here only when the user states them.
