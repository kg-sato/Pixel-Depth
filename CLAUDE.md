- **Lessons from that night:** (1) never put a `-- comment` inside a replacement that lands mid-line: twice it swallowed the rest of the line (an `end`, an argument) and broke the game; check both error logs after the LAST push, before a commit. (2) Under the Realistic style a PointLight within about 4 studs burns surfaces white, and SmoothPlastic adds a white shine: first-person parts are `Rubber`, lamps you can walk up to are 0.3 to 0.45. (3) `execute_luau` resets a Scriptable camera when the call ends, so a capture taken by a later call shows the player's own view. (4) A ProximityPrompt only shows (and `InputHoldBegin` only works) while its point is on screen: to trigger one in a test, set the camera Scriptable, aim it at the prompt, wait 0.6 s and hold, all inside ONE `execute_luau` call; put prompts for low objects on an Attachment above them.
- **Lighting style:** the game is tuned for `Lighting.LightingStyle = Realistic` (wet rock and glass reflect; the town is a real night). Scripts cannot set it: it is set in Edit mode (`spike/rebuild_place.sh` does it) and must be saved with the place.
- **Night helper:** `python spike/night.py push|play|stop|lua|shot|key|sizes` (push stops Play first and creates missing modules); `spike/grade_night.py <round>` captures one picture per audit item; `spike/hud_overlap.luau` (Client) reports HUD rectangle overlaps; `spike/mg_night.py` plays both minigames.
- World technique: mines are cells kept as data; only rock faces that look into the open cave near the player are Parts (flood fill). Not Terrain, not EditableMesh.

## Lessons carried over from the archived xianxia game (`..\Xianxia`)
- Pick an art style we can build reliably: avoid hand-modelled organic hero assets (hair, fur, dragons) as the core of the look.
- For any model from concept art: trace every part on each view at zoom with a grid and overlay the trace before building; keep each part under its triangle budget so nothing gets decimated.
- Keep the setup lean: one folder, one repo, few standing rules. Add rules here only when the user states them.
