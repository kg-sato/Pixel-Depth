### The 5 Most Important Concrete Fixes

All fixes are specified for execution using native Roblox `Part`, `WedgePart`, and `CornerWedgePart` instances:

#### Fix 1: Wisteria — Rebuild Tapered Micro-Racemes with Negative Space
* **Problem:** Wisteria canopy is a solid, blunt two-tone umbrella/skirt without vertical raceme articulation.
* **Parts & Dimensions:**
  * Delete the solid pink hanging skirt. Under the green branch plate, assemble **10–14 distinct vertical hanging racemes** spaced at least 0.6 studs apart.
  * Each raceme is built from 3 vertical interlocking Parts tapering downwards:
    * **Top Part:** `Part`, Size `1.0 x 1.4 x 1.0` studs, `Color3.fromRGB(175, 130, 205)` (Mid Lilac), `SmoothPlastic`.
    * **Mid Part:** `Part`, Size `0.7 x 1.2 x 0.7` studs, `Color3.fromRGB(205, 165, 230)` (Soft Pastel Lilac), `SmoothPlastic`.
    * **Tip Part:** `Part`, Size `0.4 x 0.8 x 0.4` studs, `Color3.fromRGB(240, 215, 255)` (Frosted White-Lilac), `SmoothPlastic`.
  * **Count:** ~36 parts total for the racemes. Hang them at staggered Y-levels (-0.5 to -1.5 studs offset) to create an organic weeping cascade.

#### Fix 2: Blossom Trees — Color Calibration for Night Ambient & Layered Cloud Pads
* **Problem:** Blossom canopies read as dead ash-grey under night lighting; branch clumps are disjointed.
* **Parts & Dimensions:**
  * **Color Compensation:** Over-saturate and brighten the palette to punch through the night ambient tint:
    * Bottom/Underside: `Color3.fromRGB(195, 80, 130)` (Rich Rose Plum).
    * Mid-body: `Color3.fromRGB(255, 160, 195)` (Vibrant Sakura Pink).
    * Crest/Top: `Color3.fromRGB(255, 225, 240)` (Frosted Butter-Pink).
  * **Canopy Geometry:** Rebuild canopy into **3–4 stepped horizontal cloud pads** per tree:
    * Core of each pad: `Part`, Size `2.0 x 0.6 x 2.0` studs.
    * Flanking florets: 5–7 perimeter `Part`s, Size `0.8 x 0.6 x 0.8` studs, offset at stepped heights to create tiered blossom clouds with visible negative space between the main boughs.
  * **Count:** 28–36 parts per tree canopy.

#### Fix 3: Bonsai — Rescale to 3× Hero Specimen with Chiseled Boulder & Lantern Cavity
* **Problem:** Bonsai is microscopic (dwarfed by a street lamp) on a flat curb; lacks presence and silhouette.
* **Parts & Dimensions:**
  * **Scale:** Scale up entire model by 2.8× (total height ~9–10 studs).
  * **Faceted Boulder:** Build a multi-faceted stone base (Footprint: `6 x 3.5 x 5.5` studs) using 6 overlapping `WedgePart` and `Part` instances in `Color3.fromRGB(90, 95, 105)` (Slate Grey), `Slate` material.
  * **Lantern Glow:** Embed 1 `Part`, Size `1.2 x 1.2 x 1.2` studs, `Material = Enum.Material.Neon`, `Color3.fromRGB(255, 195, 100)` inside a recessed cleft in the boulder face with an attached `PointLight` (Range 8, Brightness 1.5).
  * **Trunk & Roots:** 3 angled `Part` segments (`1.2 x 1.8 x 1.2` studs, rotated 15°–25°), `Color3.fromRGB(55, 40, 35)`, with 2 root wedges (`0.6 x 1.4 x 0.6` studs) visibly clutching down over the boulder's rock face.
  * **Tiered Canopy:** 3 stepped horizontal cloud pads (left low, right mid, center apex), each using 8–10 micro-parts (`0.8 x 0.6 x 0.8` studs, `Color3.fromRGB(115, 215, 175)` top / `Color3.fromRGB(55, 120, 95)` bottom).

#### Fix 4: Round Mint Tree — High-Density Micro-Voxel Shell & Gradient Tuning
* **Problem:** Lumpy, coarse blockiness with harsh near-black shadows and detached floating blocks.
* **Parts & Dimensions:**
  * Delete all detached floating blocks.
  * Rebuild the outer foliage volume using smaller, denser parts (Size `0.8 x 0.8 x 0.8` studs instead of 1.5 studs) arranged in a 3-tier vertical shell (~70–85 parts total):
    * **Under-layer (bottom 25%):** `Color3.fromRGB(45, 75, 80)` (Deep Plum/Teal shadow).
    * **Mid-canopy (middle 50%):** `Color3.fromRGB(110, 220, 175)` (Crisp Mint Green).
    * **Dome crest (top 25%):** `Color3.fromRGB(190, 250, 215)` (Frosted Butter-Mint highlight).
  * Interlock cubes into stepped "+" floret clusters (1 center block with 4 corner-inset blocks) to replicate the faceted leaf-cluster texture seen in `s81`/`s82`.

#### Fix 5: Trunks & Roots — Replace 90° Crosses with Asymmetric Fluted Wedges
* **Problem:** Roots on blossom and round trees stick out as flat, symmetric 90° rectangular bars like plastic miniature stands.
* **Parts & Dimensions:**
  * Delete the flat perpendicular root blocks.
  * Build **4 asymmetric sloping root buttresses** per tree using `WedgePart` and `CornerWedgePart`:
    * **Primary Buttress (x2):** `WedgePart`, Size `1.2 x 1.6 x 2.2` studs, sloping from trunk down into the grass at 35°, angled at irregular rotations (e.g. 0° and 115°).
    * **Secondary Buttress (x2):** `WedgePart`, Size `0.8 x 1.0 x 1.6` studs, angled at 200° and 290°.
    * **Trunk Base Transition:** Base trunk segment `Part` Size `1.8 x 2.0 x 1.8` studs tapering to mid-trunk `Part` `1.2 x 3.0 x 1.2` studs.
    * **Color:** `Color3.fromRGB(58, 44, 50)` (Warm Plum-Bark Brown), matching the ambient night palette instead of harsh pitch black.
